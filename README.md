# 抖抖的抖 / ControllerDog

抖抖的抖是一个 Windows 本地 WPF 手柄按键映射工具，用于把手柄输入一对一映射到键盘按键或鼠标按键。

项目只做手柄到键鼠的基础映射，不包含宏、连发、自动压枪、自动操作、游戏内存读写、注入、驱动级伪装、虚拟 HID 输出或内核操作。

## 当前功能

- 支持 DualShock 4 / DualSense / XInput / 常见 HID 手柄检测。
- 支持点击手柄预览图上的按键直接设置映射。
- 支持键盘、鼠标按键作为映射目标。
- 支持实时按键状态和手柄预览高亮。
- 支持保存配置、加载配置。
- 支持轮询率选择：250 / 500 / 1000 / 2000 / 4000 / 8000 Hz。
- 支持浅色 / 深色主题和主题色切换。
- 支持 DS4 / DualSense / XInput 三套手柄底图资源。
- 支持手柄热区校准，可手动拖动不准确的点击区域。

## 使用方法

1. 打开程序。
2. 连接手柄。
3. 点击“开始映射”。
4. 在中间手柄预览图上点击要映射的手柄按键。
5. 在弹出的键盘 / 鼠标面板中选择目标按键。
6. 点击“完成”保存当前按键映射。
7. 如需长期使用，点击“保存配置”。

## 热区校准

如果手柄图片和点击热区没有完全对齐：

1. 点击顶部“校准热区”。
2. 直接拖动蓝色热区到正确位置。
3. 右键某个热区可恢复该热区默认位置。
4. 点击“完成校准”退出。

校准数据会保存到当前用户的应用数据目录，下次启动自动加载。

## 编译

```powershell
dotnet build .\抖抖的抖.sln -c Release
```

## 发布单文件 exe

```powershell
dotnet publish .\抖抖的抖\抖抖的抖.csproj -p:PublishProfile=win-x64-single-file
```

发布输出目录：

```text
抖抖的抖\bin\Release\net8.0-windows10.0.19041.0\win-x64\publish\
```

## 说明

这是一个本地工具项目，目标是尽量保持轻量、清晰、低占用，并优先保证输入映射稳定性。
