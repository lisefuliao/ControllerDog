# 抖抖的抖 / ControllerDog

抖抖的抖是一个 Windows 本地 WPF 手柄按键映射工具。

它只做一件事：把手柄输入一对一映射到键盘按键或鼠标按键然后抖抖抖抖抖抖抖抖。项目不包含宏、连发、自动压枪、自动操作、游戏内存读写、注入、驱动级伪装、虚拟 HID 输出或任何复杂外挂功能。

## 当前功能

- 支持 XInput / Xbox 布局手柄识别。
- 支持 DS4 / DualShock 4 手柄识别。
- 支持 DualSense / DSE 手柄基础预览。
- 支持常见 HID 手柄基础识别。
- 支持点击手柄预览图上的按键来创建映射。
- 支持键盘、鼠标按键作为映射目标。
- 支持 DS4 的 `PS` 和 `Touchpad` 按键映射。
- 支持按键实时高亮显示。
- 支持 Light / Dark 主题和 Accent 颜色切换。
- 支持轮询率选项：250 / 500 / 1000 / 2000 / 4000 / 8000 Hz。
- 后台运行时减少 UI 刷新，只保留映射输出，降低对系统和游戏性能的影响。

## 使用方法

1. 插入手柄。
2. 打开 `抖抖的抖.exe`。
3. 在手柄预览图上点击要映射的手柄按键。
4. 在弹出的键盘/鼠标面板里选择目标按键。
5. 点击“完成”保存本次映射。
6. 点击“开始映射”。
7. 进入游戏或桌面环境测试。

如果要修改某个按键映射，直接再次点击手柄预览图上的对应按键即可。

## 热区校准

如果手柄图片和点击热区没有完全对齐，可以点击顶部的“校准热区”：

- 拖动任意热区来调整位置。
- 松开鼠标后自动保存。
- 右键某个热区可恢复默认位置。
- 再次点击“完成校准”退出校准模式。

校准数据保存在当前 Windows 用户的应用数据目录中，不会影响映射配置。

## 注意事项

- Xbox 手柄中间的 Xbox / Guide 键在很多 Windows 环境里会被系统或 Game Bar 接管，不保证可映射。
- 如果游戏以管理员权限运行，建议本工具也用管理员权限运行。
- 如果游戏内没有反应，先在桌面或记事本里测试映射是否正常。

## 项目定位

这个工具用于普通玩家把手柄按键映射成键鼠输入，方便不同游戏或个人习惯使用。它不是外挂，也不提供自动化游戏行为。
