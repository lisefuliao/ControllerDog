# 抖抖的抖

抖抖的抖是一个 Windows 本地 WPF 手柄按键映射工具，作者署名：马德锦大神。

它只做一件事：把手柄输入一对一映射到键盘按键或鼠标按键。项目不包含宏、连发、自动压枪、自动操作、游戏内存读写、注入、驱动级伪装、虚拟 HID 输出或任何复杂外挂功能。

## 下载

普通玩家不需要编译项目，直接到 GitHub Releases 下载最新版 exe 即可：

[下载最新版](https://github.com/lisefuliao/ControllerDog/releases/latest)

下载后双击运行 `抖抖的抖.exe`。

## 当前功能

- 支持 XInput / Xbox 布局手柄识别。
- 支持 DS4 / DualShock 4 手柄识别。
- 支持常见 HID 手柄基础识别。
- 支持点击手柄预览图上的按键来创建映射。
- 支持键盘、鼠标按键作为映射目标。
- 支持 DS4 的 `PS` 和 `Touchpad` 按键映射。
- 支持按键实时高亮显示。
- 支持后台运行时只保留映射效果，减少 UI 刷新对游戏性能的影响。
- 支持轮询率选项：250 / 500 / 1000 / 2000 / 4000 / 8000 Hz。

## 使用方法

1. 插入手柄。
2. 打开 `抖抖的抖.exe`。
3. 在手柄预览图上点击要映射的手柄按键。
4. 在弹出的键盘/鼠标图里选择目标按键。
5. 点“完成”保存本次映射。
6. 点“开始映射”。
7. 进入游戏测试。

如果要修改某个按键映射，直接再次点击手柄预览图上的对应按键即可。

## 最近更新

### 当前版本

- 去掉中间映射表，改为直接点击手柄预览图进行映射。
- 键鼠选择窗口改为图形化键盘/鼠标布局。
- 选择映射目标后会高亮显示，点“完成”后才保存关闭。
- XInput 模式下隐藏 DS 专属的 `PS` / `Touchpad` UI。
- DS4 模式下实时按键状态显示 DS 风格名称，例如 `L2`、`R2`、`Cross`、`Circle`。
- 保留 DS4 的 `PS` 和 `Touchpad` 映射。
- 降低 DS4 UI 高亮反馈延迟。
- 后台运行时减少 UI 刷新，只保留映射输出，降低系统和游戏性能占用。

### 第二版重构基础

- 增加 DS4 / HID / XInput 检测。
- 增加 ButtonDown / ButtonHeld / ButtonUp 防抖状态机。
- 输入读取线程与 UI 线程分离。
- Auto 模式优先 XInput，无法读取时 fallback HID。
- 修复映射编辑弹窗卡死问题。
- 修复 DS4 按键闪烁、重复触发和状态不稳定问题。

## 注意事项

- Xbox 手柄中间的 Xbox / Guide 键在很多 Windows 环境里会被系统或 Game Bar 接管，当前版本不作为可映射按键展示。
- 如果游戏以管理员权限运行，建议本工具也用管理员权限运行。
- 如果游戏内没有反应，先在桌面或记事本里测试映射是否正常。

## 项目定位

这个工具用于普通玩家把手柄按键映射成键鼠输入，方便不同游戏或个人习惯使用。它不是外挂，也不提供自动化游戏行为。
